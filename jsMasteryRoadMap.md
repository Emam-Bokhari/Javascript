# Complete JavaScript Mastery Roadmap

| **Main Topics**                    | **Subtopics**                                                                                                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Fundamentals**                | - Variables (`var`, `let`, `const`) <br> - Data Types (primitive, reference) <br> - Operators (Arithmetic, Logical, Bitwise) <br> - Control Flow (`if-else`, loops, `switch`)      |
| **2. Functions**                   | - Function Declaration and Expressions <br> - Arrow Functions <br> - Parameters and Defaults <br> - Rest/Spread in Functions <br> - IIFE (Immediately Invoked Function Expression) |
| **3. Objects**                     | - Object Creation (`{}`, `Object.create`) <br> - Prototypes and Inheritance <br> - `this` Keyword <br> - Object Methods (`assign`, `keys`, `values`, `freeze`, `seal`)             |
| **4. Arrays**                      | - Creation and Methods (`map`, `filter`, `reduce`, `forEach`, `slice`, `splice`, `sort`) <br> - Iterators (`for...of`, `entries`, `keys`)                                          |
| **5. ES6+ Features**               | - Template Literals <br> - Destructuring Arrays/Objects <br> - Symbols <br> - Optional Chaining (`?.`) <br> - Nullish Coalescing (`??`)                                            |
| **6. DOM Manipulation**            | - Selecting Elements (`getElementById`, `querySelector`) <br> - Event Handling (`addEventListener`, delegation) <br> - Modifying Styles/Classes/Attributes                         |
| **7. Asynchronous JavaScript**     | - Callbacks <br> - Promises (`.then`, `.catch`, `.finally`) <br> - `async/await` <br> - `setTimeout` and `setInterval`                                                             |
| **8. Error Handling**              | - `try-catch-finally` <br> - Throwing Custom Errors <br> - Error Objects (`name`, `message`, `stack`)                                                                              |
| **9. Regular Expressions (RegEx)** | - Patterns, Flags <br> - Methods (`test`, `exec`) <br> - String Integration (`match`, `search`, `replace`)                                                                         |
| **10. Advanced Topics**            | - Closures <br> - Hoisting <br> - Scope (global, block, function) <br> - Currying <br> - Functional Programming Concepts (immutability, pure functions)                            |
| **11. Event Loop**                 | - Call Stack <br> - Task Queue <br> - Microtasks vs Macrotasks <br> - Event Propagation (capturing, bubbling)                                                                      |
| **12. Advanced Objects**           | - Getters/Setters <br> - `Object.defineProperty` <br> - Object Prototype Chain <br> - Object Composition                                                                           |
| **13. Classes and OOP**            | - ES6 Classes and Constructors <br> - `super` and `extends` <br> - Static vs Instance Methods <br> - Private Fields (`#`)                                                          |
| **14. Modules**                    | - ES6 Modules (`import`, `export`) <br> - Dynamic Imports <br> - CJS vs ESM <br> - Bundling (Webpack, Vite)                                                                        |
| **15. Performance**                | - Debouncing and Throttling <br> - Memory Management (Garbage Collection) <br> - Optimizing Loops and DOM Interaction                                                              |
| **16. Web APIs**                   | - Fetch API <br> - `localStorage` and `sessionStorage` <br> - Geolocation <br> - Notifications API                                                                                 |
